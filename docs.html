1. System Overview

AeroScript is a domain-specific programming language designed for autonomous drone flight path synthesis. Source code written in .drone format is processed through lexical tokenization, context-free parsing, Abstract Syntax Tree (AST) construction, semantic safety verification, trigonometric interpretation, and 60 FPS 3D trajectory rendering.

5. Detailed Command Reference & Parameters

5.1 START

Initializes the drone simulation sequence and powers up engine systems.

Syntax: START

Parameters: None

5.2 STOP

Immediately halts drone operations and terminates execution safely.

Syntax: STOP

Parameters: None

5.3 TAKEOFF

Ascends the drone from grounded state to initial flight altitude (2.0 meters).

Syntax: TAKEOFF

5.4 LAND

Descends the drone to 0.0m altitude and sets airborne status to false.

Syntax: LAND

5.5 MOVE

Moves the drone in a specified direction by a given distance in meters.

Syntax: MOVE <DIRECTION> <DISTANCE>

  • DIRECTION: FORWARD | BACKWARD | LEFT | RIGHT | UP | DOWN
  • DISTANCE: Positive float (e.g. 10, 5.5)

5.6 TURN

Rotates the drone's heading angle relative to current orientation.

Syntax: TURN <DIRECTION> <DEGREES>

  • DIRECTION: LEFT | RIGHT
  • DEGREES: Angle in degrees (0–360)

5.7 HOVER

Maintains stationary position for a specified time duration.

Syntax: HOVER <SECONDS>

5.8 REPEAT

Executes an enclosed block of statements multiple times.

Syntax: REPEAT <COUNT> [ <STATEMENTS> ]

6. Semantic Analysis & Safety Checks

Rule 1: Engine Initialization Requirement
Issuing TAKEOFF before the START command generates a semantic error (TAKEOFF issued before START command).
Rule 2: Pre-flight Movement Prevention
Issuing MOVE, TURN, or HOVER before TAKEOFF results in a semantic error logged with exact line numbers.
Rule 2: Altitude Ceiling Constraint
Max altitude is strictly capped at 30.0 meters. Ascending above 30m triggers an altitude limit warning.
Rule 3: Battery Discharge Physics Model
• Movement: Battery Drain = Distance × 1.2%
• Hovering: Battery Drain = Duration × 0.5%/sec
